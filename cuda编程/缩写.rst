缩写
===========
CUDA:Compute Unified Device Architecture(计算统一设备架构)

OpenACC: open accelerators

HPC:High Performance Computing

GPU:Graphics Processing Unit

ILP:Instruction-Level Parallelism

BLAS:Basic Linear Algebra Subprograms

CUPTI:CUDA Profiling Tools Interface

CDP:CUDA dynamic parallelism

MPS：Multi-Process Service

MPI: Message Passing Interface

DGX:NVIDIA推出的一系列面向深度学习和高性能计算的服务器与工作站系统。NVIDIA官方没有给出DGX的全称，常见的"Deep Learning GPU System"只是民间说法。

NCCL:NVIDIA Collective Communication Library

NVTX:NVIDIA Tools Extension

NVML:NVIDIA Management Library

ECC:error-correcting code

LCN：Local Contrast Normalization，局部对比度归一化，早期卷积神经网络中使用的一种归一化层。
它对每个位置减去其邻域内的（加权）均值，再除以邻域内的标准差，从而消除局部亮度和对比度的差异，使特征对光照变化更鲁棒。
cuDNN中的cudnnDivisiveNormalizationForward()可用于实现LCN。

SIMT:Single Instruction Multiple Threads

TLB:Translation Lookaside Buffer
